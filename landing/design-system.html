CUE / DESIGN SYSTEM / V0.1

A quieter space
for getting things done.

A restrained, product-led system for Cue, inspired by Devin’s neutral palette and clear hierarchy. Cue keeps its own wordmark, notch symbol, and voice-first interface.

01 · Color

Near-black content on a soft gray canvas. White surfaces separate interface layers; sage is reserved for subtle progress indicators.

Muted text is for secondary copy on the gray canvas. Keep small text on white in a darker neutral when contrast is insufficient.

02 · Typography

Geist, supplied with Cue. Regular-weight headings, compact tracking, comfortable body copy. Devin’s proprietary typeface is not bundled.

03 · Space & shape

An 8px spacing rhythm: 8, 16, 24, 32, 48, 64, 96. Content width: 1248px. Page gutters: 32px desktop and 24px mobile. Cards use 12px corners; buttons use full pills.

05 · Product behavior

The native pill is 230 × 42px. Its scoop contour comes from Cue’s IslandShape component, with a 20px dot matrix and 14px Geist status text. Use this exact SVG rather than a rounded rectangle.

Listening → Transcribing → Running briefly → Hidden background work. Hold right Option for 1.5 seconds to peek at Planning or the running-agent count and elapsed time; release to hide. Completion shows a green matrix and “Results ready.” Clicking it expands the result scoop downward from the top edge.

The website uses a static workflow storyboard. Product shapes and state order are taken from the supplied Cue source.
