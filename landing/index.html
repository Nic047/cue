What is Cue?

Cue is a voice-driven AI assistant that lives in your MacBook’s notch as a small pill. Give it a task, keep working, and check back when the result is ready.

Is it always listening?

No. Cue records when you ask it to. Tap right Option to start speaking, then tap again when you’re done.

Can I see the source?

Yes. Cue is open source—for now.

What do I need to run it?

An Apple Silicon Mac and your own Solari, Vercel AI Gateway, and Groq API keys. Onboarding helps you set them up. This alpha isn’t notarized, so macOS may require you to allow it in System Settings → Privacy & Security after you try opening it.

How early is “alpha”?

Early enough that this page says “absolutely no one.” Expect rough edges as Cue takes shape.

Install Cue
  1. Open Cue.dmg and drag Cue to Applications.
  2. Try opening Cue. If macOS blocks it, go to System Settings → Privacy & Security, scroll to the security section, click Open Anyway (Dennoch öffnen), and confirm Open. Cue isn’t Apple-notarized yet, so macOS can’t verify this build.
